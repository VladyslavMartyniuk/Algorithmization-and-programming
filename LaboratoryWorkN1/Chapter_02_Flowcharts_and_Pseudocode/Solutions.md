# Розділ 2. Блок-схеми та псевдокод — розв'язання

Блок-схеми подано у Mermaid: GitHub відображає їх як діаграми. У псевдокоді `←` означає присвоєння, `mod` — остачу від ділення, `div` — цілу частку.

## 2.1 Максимум із трьох чисел; тест `(5, 9, 2)`

```mermaid
flowchart TD
 A([Початок]) --> B[/Ввести a, b, c/]
 B --> C[m ← a]
 C --> D{b > m?}
 D -- так --> E[m ← b]
 D -- ні --> F{c > m?}
 E --> F
 F -- так --> G[m ← c]
 F -- ні --> H[/Вивести m/]
 G --> H
 H --> I([Кінець])
```

**Псевдокод**
```text
ПОЧАТОК
  ВВЕСТИ a, b, c
  m ← a
  ЯКЩО b > m ТО m ← b ВСЕ
  ЯКЩО c > m ТО m ← c ВСЕ
  ВИВЕСТИ m
КІНЕЦЬ
```

**Таблиця трасування**

| Крок | `b > m` | `m` після перевірки `b` | `c > m` | `m` після перевірки `c` |
|---|---|---:|---|---:|
| 0 — початок | — | 5 | — | 5 |
| 1 | `9 > 5` — так | 9 | — | 9 |
| 2 | — | 9 | `2 > 9` — ні | 9 |

Вивід: `9`.

## 2.2 Знак числа; тест `−7`

```mermaid
flowchart TD
 A([Початок]) --> B[/Ввести x/]
 B --> C{x > 0?}
 C -- так --> D[результат ← додатне]
 C -- ні --> E{x < 0?}
 E -- так --> F[результат ← від'ємне]
 E -- ні --> G[результат ← нуль]
 D --> H[/Вивести результат/]
 F --> H
 G --> H
 H --> I([Кінець])
```

**Псевдокод**
```text
ПОЧАТОК
  ВВЕСТИ x
  ЯКЩО x > 0 ТО
    результат ← «додатне»
  ІНАКШЕ ЯКЩО x < 0 ТО
    результат ← «від'ємне»
  ІНАКШЕ
    результат ← «нуль»
  ВСЕ
  ВИВЕСТИ результат
КІНЕЦЬ
```

**Таблиця трасування**

| Крок | Умова | Результат перевірки | Дія |
|---|---|---|---|
| 1 | `x > 0` | `−7 > 0` — ні | Перейти до другої умови |
| 2 | `x < 0` | `−7 < 0` — так | `результат ← від'ємне` |

Вивід: `від'ємне`.

## 2.3 Факторіал `n!`; тест `n=5`

```mermaid
flowchart TD
 A([Початок]) --> B[/Ввести n/]
 B --> C[f ← 1; i ← 1]
 C --> D{i ≤ n?}
 D -- так --> E[f ← f * i; i ← i + 1]
 E --> D
 D -- ні --> F[/Вивести f/]
 F --> G([Кінець])
```

**Псевдокод**
```text
ПОЧАТОК
  ВВЕСТИ n  // n ≥ 0
  f ← 1; i ← 1
  ПОКИ i ≤ n ВИКОНУВАТИ
    f ← f * i
    i ← i + 1
  ВСЕ
  ВИВЕСТИ f
КІНЕЦЬ
```

**Таблиця трасування**

| Крок | `i` перед множенням | `f` до множення | `f` після множення | `i` після збільшення | `i ≤ 5` |
|---:|---:|---:|---:|---:|---|
| 0 | 1 | 1 | 1 | 2 | так |
| 1 | 2 | 1 | 2 | 3 | так |
| 2 | 3 | 2 | 6 | 4 | так |
| 3 | 4 | 6 | 24 | 5 | так |
| 4 | 5 | 24 | 120 | 6 | ні |

Вивід: `120`.

## 2.4 Сума цифр натурального числа; тест `1234`

```mermaid
flowchart TD
 A([Початок]) --> B[/Ввести n/]
 B --> C[s ← 0]
 C --> D{n > 0?}
 D -- так --> E[d ← n mod 10]
 E --> F[s ← s + d]
 F --> G[n ← n div 10]
 G --> D
 D -- ні --> H[/Вивести s/]
 H --> I([Кінець])
```

**Псевдокод**
```text
ПОЧАТОК
  ВВЕСТИ n  // n ≥ 0
  s ← 0
  ПОКИ n > 0 ВИКОНУВАТИ
    d ← n mod 10
    s ← s + d
    n ← n div 10
  ВСЕ
  ВИВЕСТИ s
КІНЕЦЬ
```

**Таблиця трасування**

| Ітерація | `n` до кроку | `d = n mod 10` | `s` після додавання | `n` після `n div 10` |
|---:|---:|---:|---:|---:|
| 0 | 1234 | 4 | 4 | 123 |
| 1 | 123 | 3 | 7 | 12 |
| 2 | 12 | 2 | 9 | 1 |
| 3 | 1 | 1 | 10 | 0 |

Вивід: `10`. Для `n=0` сума дорівнює `0`.

## 2.5 Кількість цифр натурального числа; тест `70500`

```mermaid
flowchart TD
 A([Початок]) --> B[/Ввести n/]
 B --> C{n = 0?}
 C -- так --> D[кількість ← 1]
 C -- ні --> E[кількість ← 0]
 E --> F{n > 0?}
 F -- так --> G[кількість ← кількість + 1; n ← n div 10]
 G --> F
 F -- ні --> H[/Вивести кількість/]
 D --> H
 H --> I([Кінець])
```

**Псевдокод**
```text
ПОЧАТОК
  ВВЕСТИ n  // n ≥ 0
  ЯКЩО n = 0 ТО
    кількість ← 1
  ІНАКШЕ
    кількість ← 0
    ПОКИ n > 0 ВИКОНУВАТИ
      кількість ← кількість + 1
      n ← n div 10
    ВСЕ
  ВСЕ
  ВИВЕСТИ кількість
КІНЕЦЬ
```

**Таблиця трасування**

| Ітерація | `n` до кроку | Кількість після збільшення | `n` після `n div 10` |
|---:|---:|---:|---:|
| 0 | 70500 | 1 | 7050 |
| 1 | 7050 | 2 | 705 |
| 2 | 705 | 3 | 70 |
| 3 | 70 | 4 | 7 |
| 4 | 7 | 5 | 0 |

Вивід: `5`. Для `n=0` кількість цифр — `1`.

ПОЧАТОК

## 2.7 НСД за алгоритмом Евкліда з відніманням; тест `(48, 18)`

```mermaid
flowchart TD
 A([Початок]) --> B[/Ввести a, b/]
 B --> C{a ≠ b?}
 C -- так --> D{a > b?}
 D -- так --> E[a ← a - b]
 D -- ні --> F[b ← b - a]
 E --> C
 F --> C
 C -- ні --> G[/Вивести a/]
 G --> H([Кінець])
```

**Псевдокод**
```text
ПОЧАТОК
  ВВЕСТИ a, b  // a > 0, b > 0
  ПОКИ a ≠ b ВИКОНУВАТИ
    ЯКЩО a > b ТО
      a ← a - b
    ІНАКШЕ
      b ← b - a
    ВСЕ
  ВСЕ
  ВИВЕСТИ a
КІНЕЦЬ
```

**Таблиця трасування**

| Крок | `a` | `b` | Дія |
|---:|---:|---:|---|
| 0 | 48 | 18 | `a > b`, тому `a ← a - b` |
| 1 | 30 | 18 | `a > b`, тому `a ← a - b` |
| 2 | 12 | 18 | `a < b`, тому `b ← b - a` |
| 3 | 12 | 6 | `a > b`, тому `a ← a - b` |
| 4 | 6 | 6 | `a = b`, цикл завершується |

Вивід: `6`. Передумова: обидва числа додатні.

## 2.9 Перевірка простоти; тест `n=21`

```mermaid
flowchart TD
 A([Початок]) --> B[/Ввести n/]
 B --> C{n < 2?}
 C -- так --> D[просте ← ні]
 C -- ні --> E[d ← 2; просте ← так]
 E --> F{d < n і просте?}
 F -- так --> G{n mod d = 0?}
 G -- так --> H[просте ← ні]
 G -- ні --> I[d ← d + 1]
 I --> F
 H --> F
 F -- ні --> J[/Вивести просте/]
 D --> J
 J --> K([Кінець])
```

**Псевдокод**
```text
ПОЧАТОК
  ВВЕСТИ n
  ЯКЩО n < 2 ТО
    просте ← НІ
  ІНАКШЕ
    d ← 2; просте ← ТАК
    ПОКИ d < n І просте = ТАК ВИКОНУВАТИ
      ЯКЩО n mod d = 0 ТО
        просте ← НІ
      ІНАКШЕ
        d ← d + 1
      ВСЕ
    ВСЕ
  ВСЕ
  ВИВЕСТИ просте
КІНЕЦЬ
```

**Таблиця трасування**

| Крок | `d` | `21 mod d` | `просте` після кроку | Дія |
|---:|---:|---:|---|---|
| 0 | 2 | 1 | так | Збільшити `d` до 3 |
| 1 | 3 | 0 | ні | Знайдено дільник; завершити цикл |

Вивід: `НІ` (21 — складене).
