================================================================================
                              TYPES OF ALGORITHMS
================================================================================

CLASSIFIED BY EXECUTION STRUCTURE:

1. SEQUENTIAL (LINEAR)
   Executes instructions line-by-line from start to finish without skipping
   or repeating any steps.

2. CONDITIONAL (SELECTION / BRANCHING)
   Uses logical decisions (if / else) to execute specific code paths based
   on evaluated conditions.

3. ITERATIVE (LOOPING)
   Repeats a block of code multiple times until a specified termination
   condition is met (for / while loops).

4. RECURSIVE
   A function that solves a problem by calling itself with smaller inputs
   until reaching a base termination case.

================================================================================
