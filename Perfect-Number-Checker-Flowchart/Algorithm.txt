================================================================================
                             ALGORITHM STEPS
================================================================================

1. Input a natural number n.
2. Check if n <= 1. If true, output "Not Perfect" and stop.
3. Set sum equal to 1, and set iterator i equal to 2.
4. Check if i is less than or equal to sqrt(n).
   - If true, check if n is divisible by i (n % i == 0).
     - If divisible, add i to sum. If i is not equal to n / i, also add n / i to sum.
     - Increment i by 1 and repeat step 4.
   - If false, proceed to step 5.
5. Check if sum equals n.
   - If sum == n, output "Perfect".
   - Otherwise, output "Not Perfect".
