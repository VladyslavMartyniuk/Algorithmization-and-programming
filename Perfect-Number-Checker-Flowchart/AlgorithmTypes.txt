================================================================================
                           TYPES OF ALGORITHMS USED
================================================================================

* TRIAL DIVISION ALGORITHM (OPTIMIZED BRUTE-FORCE)
  Systematically checks integers up to floor(sqrt(n)) to locate all factor 
  pairs without searching up to n-1.

* ITERATIVE ALGORITHM
  Relies on a sequential loop structure running from i = 2 to floor(sqrt(n)) 
  rather than recursive call stacks.

* DETERMINISTIC ALGORITHM
  Operates with fixed, reproducible logic that produces identical results 
  for any input n without probabilistic or randomized elements.

* DECISION ALGORITHM
  Solves a binary decision problem, returning a discrete boolean result 
  (Perfect vs. Not Perfect).

* IMPERATIVE / PROCEDURAL ALGORITHM
  Changes internal state explicitly through sequentially executed statements, 
  conditional branching, and variable accumulation (sum).

================================================================================
